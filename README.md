# Arc Token Explorer

A live dashboard for monitoring Arc Mainnet tokens with real-time price data from DexScreener.

## What it does

- Tracks 20 tokens on Arc Mainnet (TOLLY, ARGUS, ASTRA, ADEX, ARCLAND, etc.)
- Fetches live prices, market caps, FDV, 24h volume, and 24h price changes
- Auto-refreshes every 60 seconds
- Shows utility vs meme token classification

## Arc integration

- Uses Arc network token data from DexScreener (Arc chain ID)
- Demonstrates Arc ecosystem token diversity
- All data sources are public APIs, no wallet connection required

## Live demo

https://arc-dashboard-sepia.vercel.app

## Tech stack

- Vanilla HTML/CSS/JS (no framework)
- DexScreener API for token data
- Vercel for hosting

## How to run locally

```bash
# Just open index.html in a browser
open index.html
```
